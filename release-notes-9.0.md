# Screenator 9.0

Screenator 9.0 brings together the accumulated 8.1 and 8.2 updates with
refinements to Paper-mode navigation and shortcut handling.

Updated: 2026-11-19

## Linux

- Screen-mode Ctrl shortcuts run only while a drawing tool is active.
- Paper-mode shortcuts and Escape are scoped to the active Screenator window.
- Toggle Visibility now behaves consistently across Screen and Paper modes and
  remains unchanged when selecting tools.
- Companion apps stay above Paper while the desktop panel remains hidden, and
  command or path changes appear on the toolbar immediately.
- Polar math plots now follow the standard counterclockwise direction as θ
  increases.
- Updated icons, defaults, drawing behavior, and package metadata.

## Windows

- Updated toolbar, color presets, and Paper-mode behavior.
- Paper-mode shortcut handling is scoped to the active Screenator window.
- See the [Windows guide](screenator-windows/README.md) and
  [Windows release notes](screenator-windows/RELEASE_NOTES.md) for details.

## Packages

- Linux: `screenator_9.0_amd64.deb`, `screenator-9.0-1.x86_64.rpm` and
  `Screenator-9.0-x86_64.AppImage`.
- Windows: `Screenator-9.0-win64.zip` and
  `Screenator-9.0-win64-setup.exe`.
- `SHA256SUMS.txt` contains checksums for all five packages.
