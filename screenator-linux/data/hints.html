Screenator Hints

Introduction

  • Screenator has a Screen and a Paper annotion modes.
  • Tools can be selected from Floating Icon, Tool Bar, and System Try Icon

Global Shortcuts

  • F3 switches between Screen and Paper annotation mode.
  • F9 shows or hides the floating icon.
  • F10 shows or hides the toolbar.
  • Tool selection: F8 Pen, F Text, F6 Arrow, F12 Timer
  • F4 saves a screenshot in the Picture folder.
  • ESC key exit shape handles and exit current tool in Screen mode.

Paper Mode Shortcuts

  • CTRL+Z undo, CTRL+SHIFT+Z redo.
  • CTRL+t Toggle Visibility.
  • CTRL+q exit Paper Mode.
  • ALT-F4 Close Screenator.
  • CTRL-w Show paper as window.
  • CTRL-d Show desktop panel.

Mouse in Screen Mode>

  • Left click draw using active tool.
  • Long midel click activate erasor.
  • Long right click opens the Scroll Mode menu and chooses Color or Thickness.
  • Right click escapes shape handles,and exit current tool

Mouse in Paper Mode>

  • Left click draw using active tool.
  • Midel click activate erasor.
  • Right click escapes shape handles, and activate erasor, it does not exit current tool.

Stylus

  • In stylus configuration (of your operating system), set Button 1 (The one near stylus tip) to middle mouse click, and Button 2 to right mouse click.
  • Short pressing Button 1 acts as mouse scroll and long pressing acts as long pressing the middle mouse button
  • Short pressing Button 2 acts as right mouse click adn long pressing acts as long pressing the right mouse button

Text Tool

  • After typing, press Enter to accept the text and re-enable the mouse. While typing, the mouse wheel and stylus side button 1 change the text colour, and right click cancels the text like Escape.

Marker Tool

  • The wheel or stylus side button 1 changes its color.
  • Long right click or Long press side button 2 opens the Marker Opacity menu.
