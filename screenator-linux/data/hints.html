Screenator Hints

Introduction

  • Screenator has two annotation modes: Screen Mode to annotate directly on the screen, and Paper Mode to annotate on a paper or a PDF file.
  • Tools can be selected from the Floating Icon, Toolbar, or System Tray icon.

Global Shortcuts

  • F3 switches between Screen and Paper annotation modes. The current tool is closed and Cursor is selected.
  • F9 shows or hides the Floating Icon.
  • F10 shows or hides the Toolbar.
  • Tool selection: F8 Pen, F7 Text, F6 Arrow, F12 Timer.
  • F4 saves a screenshot in the Pictures folder.
  • The Esc (Escape) key closes shape handles and exits the current tool in Screen mode.
  • Hold the Ctrl key to:
    • Snap to 0°, 30°, 45°, 60°, 90°, etc. while rotating or creating shapes.
    • Apply a 1:1 aspect ratio to a rectangle or ellipse.
    • Control an individual Spline handle.

Paper Mode Shortcuts

  • Ctrl+Z undoes the last action; Ctrl+Shift+Z redoes it.
  • Ctrl+Q exits Paper mode.
  • Alt+F4 closes Screenator.
  • Ctrl+W shows the paper in a window.
  • Ctrl+D shows the desktop panel.
  • Ctrl+S saves Paper as a PDF; Ctrl+O opens a PDF.
  • Ctrl+B inserts a page before the current page; Ctrl+A inserts one after it.
  • Page Up/Page Down moves between pages. Home/End goes to the first/last page.

Mouse

  • Left Button draws using the active tool.
  • Middle Button and Mouse Wheel change color when editing text or shapes and scroll in Page Mode
  • Right click closes shape handles, ends text typing, and erases.

Stylus

  • In your stylus configuration, set Button 1 (the one nearest the tip) to Middle Mouse Click, and Button 2 to Right Mouse Click.

Text Tool

  • After typing, press Enter, right-click, or stylus Button 2 to accept the text and re-enable the mouse. The Esc (Escape) key cancels the text.

Timer Tool

  • Timer Tool freezes the screen and activates Pen Tool when the time delay finishes. It is useful for starting annotation after an event (like opening right click context menu. Press Esc key to exit the tool.

Saving

  • Screenshots are saved automatically in the Pictures folder with the current date and time stamp.
  • Paper PDFs are saved automatically in the Documents folder with the current date and time stamp.
