# Screenator 9.1

Screenator 9.1 adds PDF text selection in Cursor mode, improves Windows text
editing, and fixes stylus tip input on Linux. See the
[GitHub release](https://github.com/malnaanah/screenator/releases/tag/v9.1)
for downloads and checksums.

Updated: 2026-11-22

## Linux

- Select and copy PDF text in Cursor mode with precise glyph selection and
  Arabic word order handling.
- Stylus tip contact events with missing or zero pressure are no longer
  mistaken for side-button clicks.

## Windows

- Improved multiline text editing and line navigation shortcuts.
- Fixed caret movement across Arabic lines.
- Added PDF text selection in Cursor mode.

## Packages

- Linux: `screenator_9.1_amd64.deb`, `screenator-9.1-1.x86_64.rpm`, and
  `Screenator-9.1-x86_64.AppImage`.
- Windows: `Screenator-9.1-win64-setup.exe` and
  `Screenator-9.1-win64.zip`.
