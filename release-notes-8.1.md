# Screenator 8.1

Screenator 8.1 updates the Linux and Windows applications with clearer save
and visibility controls, improved toolbar behavior, and refined Paper-mode
shortcuts and navigation. Linux and Windows use separate native
implementations.

Updated: 2026-11-14

## Linux

- Toggle Visibility is available in Screen and Paper modes and uses open-eye
  and closed-eye icons to show the current state. Screen mode starts with
  drawings visible, even when no drawings are restored.
- Delete clears the current Screen or Paper page. Ctrl+X deletes the current
  Paper page; both shortcuts can be changed in Settings > Shortcuts.
- Screenshot is a separate toolbar action in both modes. Save Paper appears
  only in Paper mode. The successful screenshot message can be disabled while
  errors remain visible.
- Toolbar position can be locked. Changing between horizontal and vertical
  directions places the toolbar at the corresponding screen edge.
- The floating-icon settings indicator can be changed while the icon is
  hidden, without showing the icon.
- Right-click opens the toolbar application menu, including from inactive
  icons; middle-click does not.
- Paper-mode page actions and visibility controls have clearer availability
  and tooltips, and PDF export and paper navigation have been improved.

## Windows

- Added wheel and Up/Down page navigation when continuous scrolling is off.
- Split Screenshot and Save toolbar actions, added eye-state visibility icons,
  and made visibility toggling available in both modes.
- Added toolbar position locking, direction-based placement and settings for
  screenshot and PDF-save success messages.
- Added Delete and Ctrl+X page actions, made toolbar page deletion available
  for multi-page PDFs, and changed the toolbar application menu to open with
  right-click only.
- See the [Windows guide](screenator-windows/README.md) and
  [Windows release notes](screenator-windows/RELEASE_NOTES.md) for details.
