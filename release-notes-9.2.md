# Screenator 9.2

Screenator 9.2 keeps Linux drawing and paper page changes in one undo/redo
sequence. Undoing a page deletion restores the page, then subsequent undo
steps reverse the drawing and page creation actions in their original order.

Updated: 2026-11-24

## Linux

- Preserve drawing undo history when inserting or deleting a paper page.
- Build Linux packages with version 9.2.
